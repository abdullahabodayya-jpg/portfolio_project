# Personal Portfolio Website

A personal portfolio website built to showcase my skills, projects, background, and contact information as a web developer.

## About the Project

This project is a responsive personal portfolio website designed to present my work and development journey in a simple and modern way.

The website includes multiple pages that provide information about me, my projects, resume, and ways to get in touch.

* About
* Projects
* Resume
* Contact

## Getting Started

To run the project locally:

1. Clone the repository.

```bash
git clone https://github.com/abdullahabodayya-jpg/portfolio_project.git
```

2. Open the project folder.

```bash
cd portfolio_project
```

3. Open `index.html` in your browser.

No additional dependencies are required.
